# assistant-orchestrator

Personal assistant operating rules for this workspace. Use when the user asks about schedules, reminders, Apple Notes/Reminders/Calendar syncing, weekly/monthly planning, skill discovery, or OpenClaw agent-swarm orchestration. Also use when the user says the assistant should take over, asks to remember a workflow, or wants rules summarized into an auto-applied skill.
